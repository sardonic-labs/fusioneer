# Security Policy

## Reporting a Vulnerability

Open a private security advisory via GitHub **Security → Report a vulnerability** or email `security@sardonic-labs.com`. Do not open a public issue.

Include steps to reproduce, impact, and `opencode --version` / `bun --version` if relevant. We aim to acknowledge within 48h.

## Supported Versions

`main` only (pre-1.0). Pin via commit SHA until tags exist.
